Desktop app for browsing anime and manga, keeping a watch list, and picking up where you left off.

## Features

- Home page with featured titles, latest episodes, top airing, and upcoming
- Anime and manga browsing
- Manga reader
- Watch animes, sub and dub
- All DLS no embedded which means AD-free
- Resume from saved watch progress
- Continue watching, with a view all history for your continued watching
- Release inbox for anime on your list keep up to date
- Anime release schedule
- Local profiles can have multiple if more then one person uses the desktop
- Settings for your profile, scoring, theme, 18+ titles, AniList import, and sync more coming soon
- Library (metadata) stored on your PC everything is local and can be updated through settings, some features that are lightweight are enabled by default for the best experience
+ + + Plus More
